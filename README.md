# Rampage Alpaca

基于微信小游戏原生 Canvas 的轻量反应游戏，以“熊老板压迫羊驼不停砍树”为荒诞职场主题。玩家点击屏幕左、右半区控制羊驼砍树，在体力耗尽之前躲避树枝、收集道具并挑战好友纪录。

## 运行

1. 使用微信开发者工具导入项目目录，项目类型选择“小游戏”。
2. 使用项目 AppID 编译；好友排行榜需要真机和微信好友数据权限。
3. 本地逻辑测试使用 Node.js 18 或更高版本，执行 `npm test`，无需安装第三方依赖。

## 当前玩法

- 点击左/右半区切换站位并砍树一次；同侧树枝会导致游戏结束。
- 每 30 分升一级。等级越高，空层概率越低、体力消耗越快（最高 30 点/秒）。
- 连击必须在 0.9 秒内续上；连击每 5 次提升倍率，最高 4 倍。
- 初始体力为 100，每次成功砍树恢复 8 点，体力耗尽也会结束游戏。
- 每次砍树有轻微画面抖动、砍树音效和触感反馈；后台时游戏计时和音频暂停。
- 每次砍树会从主树干处飞出一小节木段，伴随旋转和淡出；碎片仅用于视觉表现。
- 连击倍率提升时播放 `assets/audio/point.mp3`；底部声音开关控制背景音乐与音效。
- 游戏结束后点击一次即可重开并完成第一下砍树。

## 道具

达到 15 分后，道具可能从树的左侧或右侧落下。每次最多一个道具，1.8 秒落到角色高度并停留 2 秒；角色处于同侧且道具已落地时自动拾取。若跨侧会撞上下一根树枝，道具会自动取消。

- 咖啡：体力回满，3 秒内不消耗。
- 摸鱼许可证：抵挡一次树枝碰撞，使用后许可证失效。
- 绩效奖金：持续 3 秒无敌，撞到树枝时将其击飞，并播放熊抽羊驼动画。
- 大饼：持续 4 秒，体力消耗速度降低 50%。

道具目前使用 Canvas 绘制的咖啡杯、许可证、钞票和饼状图标。绩效奖金免疫的是树枝碰撞，期间仍然消耗体力；已有的摸鱼许可证不会被奖金状态下的碰撞消耗。重复拾取限时道具会刷新持续时间，许可证最多持有一次抵挡机会。

为兼容现有逻辑，内部常量仍沿用 `ENERGY_FRUIT`（咖啡）、`SHIELD`（摸鱼许可证）、`BERSERK_AXE`（绩效奖金）和 `BARK_CHARM`（大饼）。数值集中在 `src/constants.js`。

## 好友排行榜

结算页点击“好友排行榜”打开，可上下滑动查看好友最高分，自己的条目会高亮。成绩使用第 1 赛季键 `rampage-alpaca-season-1`，通过开放数据域上传至微信托管存储；网络失败后每 15 秒重试，重启时根据本地纪录重新同步。共享画布按显示尺寸与设备像素比例适配。

排行榜绘制位于 `open-data/`，好友头像、昵称和成绩不会回传主游戏域。客户端托管成绩不提供服务端防作弊，好友数据和排行榜显示需使用真实 AppID、微信好友账号进行验证。

## 代码结构

- `game.js`：小游戏入口、触摸和前后台事件。
- `src/game.js`：状态机、游戏循环、计分、碰撞和效果。
- `src/tree.js`：树枝队列和安全生成规则。
- `src/drops.js`：道具下落、停留、拾取和安全取消。
- `src/renderer.js`：Canvas 绘制、适配、HUD 和特效。
- `src/progression.js`：等级、空层概率和体力消耗公式。
- `src/audio.js`：砍树、连击、升级、道具、碰撞和背景音乐。
- `src/storage.js`：本地赛季最高分。
- `src/leaderboard.js`、`open-data/index.js`：好友排行榜主域与开放数据域。
- `tests/`：树枝队列、道具、计分、重开和排行榜同步的自动测试。
- `temp/`：临时素材目录，不纳入 Git 和小游戏打包。

## 验证

提交前运行 `npm test` 和 `git diff --check`。自动测试不能替代微信运行环境验证：真机需检查连续点击、四种道具、前后台恢复、音频触感，以及两个好友账号的成绩同步、排行榜清晰度与滑动交互。

## 资源与已知限制

当前使用固定设计分辨率 `750×1334`，运行时会按屏幕缩放。角色素材和资源预加载尚未专门压缩优化；狂暴组合图尺寸较大，首次加载性能需要在目标机型上确认。排行榜、音频和触感在部分开发者工具模拟器中可能不可用，但不应阻止核心玩法运行。
