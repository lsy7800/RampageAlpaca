# Rampage Alpaca

基于微信小游戏原生 Canvas 的轻量反应游戏。玩家点击屏幕左、右半区控制角色砍树，并避开落下的树枝。

## 运行

1. 使用微信开发者工具导入项目目录，项目类型选择“小游戏”。
2. 使用项目 AppID 编译；好友排行榜需要真机和微信好友数据权限。
3. 运行测试：`npm test`。

## 当前玩法

- 点击左/右半区切换站位并砍树一次；同侧树枝会导致游戏结束。
- 每 30 分升一级。等级越高，空层概率越低、体力消耗越快（最高 30 点/秒）。
- 连击必须在 0.9 秒内续上；连击每 5 次提升倍率，最高 4 倍。
- 每次砍树有轻微画面抖动、砍树音效和触感反馈；后台时游戏计时和音频暂停。
- 游戏结束后点击一次即可重开并完成第一下砍树。

## 道具

达到 15 分后，道具可能从树的左侧或右侧落下。每次最多一个道具，1.8 秒落到角色高度并停留 2 秒；角色处于同侧且道具已落地时自动拾取。若跨侧会撞上下一根树枝，道具会自动取消。

- 体力果实：体力回满，3 秒内不消耗。
- 护盾：抵挡一次树枝碰撞。
- 狂暴斧：持续 3 秒无敌，撞到树枝时将其击飞，并播放熊抽羊驼动画。

## 好友排行榜

结算页点击“好友排行榜”打开，可上下滑动查看好友最高分，自己的条目会高亮。成绩使用第 1 赛季键 `rampage-alpaca-season-1`，新纪录会同步到微信开放数据域；网络失败时保留待同步成绩并自动重试。

排行榜绘制位于 `open-data/`，好友头像、昵称和成绩不会回传主游戏域。客户端托管成绩不提供服务端防作弊，好友数据和排行榜显示需使用真实 AppID、微信好友账号进行验证。

## 代码结构

- `game.js`：小游戏入口、触摸和前后台事件。
- `src/game.js`：状态机、游戏循环、计分、碰撞和效果。
- `src/tree.js`：树枝队列和安全生成规则。
- `src/drops.js`：道具下落、停留、拾取和安全取消。
- `src/renderer.js`：Canvas 绘制、适配、HUD 和特效。
- `src/progression.js`：等级、空层概率和体力消耗公式。
- `src/audio.js`：砍树、连击、升级、道具、碰撞和背景音乐。
- `src/storage.js`：本地赛季最高分。
- `src/leaderboard.js`、`open-data/index.js`：好友排行榜主域与开放数据域。

## 资源与已知限制

当前使用固定设计分辨率 `750×1334`，运行时会按屏幕缩放。角色素材和资源预加载尚未专门压缩优化；狂暴组合图尺寸较大，首次加载性能需要在目标机型上确认。排行榜、音频和触感在部分开发者工具模拟器中可能不可用，但不应阻止核心玩法运行。
