# Rampage Alpaca

基于微信小游戏原生 Canvas 的轻量反应游戏原型。

## 运行

1. 使用微信开发者工具导入本目录。
2. 项目类型选择「小游戏」。
3. 填入自己的小游戏 AppID 后编译运行。

## 当前玩法

点击屏幕左/右半区，角色切换到对应一侧并砍树一次。每次砍树会让树枝下降一格；若角色所在一侧被树枝击中，游戏结束。

## 架构

- `game.js`：微信小游戏入口与触摸事件转发。
- `src/game.js`：状态机、游戏循环、碰撞结算。
- `src/tree.js`：树枝队列及可反应的随机生成规则。
- `src/renderer.js`：Canvas 绘制、设计分辨率适配、HUD 与界面。
- `src/storage.js`：最高分本地持久化。
- `src/audio.js`：小游戏音效管理；当前接入砍树音效。
